# Интернет-магазин одежды

> Курсовая работа по теме: «Разработка интернет-магазина одежды»

Данный репозиторий содержит исходный код и конфигурацию для развертывания веб-приложения интернет-магазина с использованием контейнеризации.

## Стек технологий
- **Backend:** Python, Django
- **База данных:** PostgreSQL
- **Веб-сервер / Проксирование:** Nginx
- **Контейнеризация:** Docker, Docker Compose

---

## Требования к системе
- Операционная система: Windows 10/11 (с поддержкой WSL 2) или macOS / Linux.
- Установленный **[Docker Desktop](https://www.docker.com/products/docker-desktop/)**.

---

## Инструкция по локальному запуску

### Шаг 1. Установка Docker Desktop
1. Скачайте и установите [Docker Desktop](https://www.docker.com/products/docker-desktop/).
2. После установки **обязательно запустите** приложение Docker Desktop. Дождитесь появления зеленой надписи *"Engine running"* в левом нижнем углу (это необходимо для инициализации Linux VM).

### Шаг 2. Размещение проекта (Для Windows)
> **Важно:** Для корректной работы механизма общих папок (File Sharing) в Docker Desktop на Windows, рекомендуется разместить папку с проектом на системном диске `C:`.
1. Создайте папку, например: `C:\Project\`
2. Переместите или распакуйте папку с исходным кодом проекта в эту директорию.

### Шаг 3. Запуск контейнеров
1. Откройте папку с проектом в Проводнике.
2. Нажмите правой кнопкой мыши на пустом месте и выберите **«Открыть в терминале»** или **«Open in Windows PowerShell»**.
3. Выполните команду для сборки и запуска всех сервисов:

   ```bash
   docker compose up --build
