# Интернет-магазин одежды «Kunteynir»

> **Курсовая работа по теме:** «Разработка интернет-магазина одежды»

Данный репозиторий содержит исходный код и конфигурацию для развертывания веб-приложения интернет-магазина с использованием контейнеризации. Проект полностью готов к локальному запуску с минимальными настройками.

---

## Стек технологий

- **Backend:** Python, Django
- **Frontend (Интерактивность):** HTMX, Alpine.js *(для динамического обновления интерфейса, корзины и форм без перезагрузки страницы)*
- **База данных:** PostgreSQL
- **Веб-сервер / Проксирование:** Nginx
- **Контейнеризация:** Docker, Docker Compose
- **Система контроля версий:** Git

---

## Требования к системе

- **Операционная система:** Windows 10/11 (с обязательной поддержкой WSL 2) или macOS / Linux.
- **Docker:** Установленный и запущенный [Docker Desktop](https://www.docker.com/products/docker-desktop/).
- **Git:** Установленный [Git](https://git-scm.com/install/windows) для клонирования репозитория.

---

## Пошаговая инструкция по локальному запуску

### Шаг 1. Подготовка Docker Desktop
1. Скачайте и установите [Docker Desktop](https://www.docker.com/products/docker-desktop/).
2. Запустите приложение. Дождитесь появления зеленой надписи **"Engine running"** в левом нижнем углу окна (это означает, что виртуальная машина Linux успешно инициализирована).

### Шаг 2. Получение исходного кода (Git Clone)
>  **Важно для пользователей Windows:** Для корректной и быстрой работы механизма общих папок (File Sharing) в Docker Desktop, настоятельно рекомендуется размещать папку с проектом на системном диске `C:\` или внутри файловой системы WSL (например, `\\wsl$\Ubuntu\home\user\`). Избегайте размещения в сетевых дисках или на внешних USB-накопителях.

1. Откройте терминал (Командную строку, PowerShell или терминал WSL).
2. Перейдите в директорию, где вы хотите разместить проект:

   ```bash
   cd C:\
   
4. Склонируйте репозиторий (замените URL на актуальную ссылку вашего репозитория):

   ```bash
   git clone https://github.com/trauringetag/kunteynir.git
   
6. Перейдите в папку с клонированным проектом:

   ```bash

### Шаг 3. Запуск контейнеров
